# Bluecurve for NixOS & Home Manager

Packages and modules for theming with [Bluecurve](https://github.com/neeeeow/Bluecurve), [Bluecurve-Qt](https://github.com/neeeeow/Bluecurve-Qt) and [Bluecurve-KDE](https://github.com/neeeeow/Bluecurve-KDE).

**[Documentation](https://docs.rtin.foo/bluecurve.nix/)** · [Home Manager](https://docs.rtin.foo/bluecurve.nix/home-manager/) · [NixOS](https://docs.rtin.foo/bluecurve.nix/nixos/)

## Features

* GTK, Qt and desktop environments (MATE, KDE Plasma, Xfce) for [Home Manager](https://docs.rtin.foo/bluecurve.nix/home-manager/) via `bluecurve.homeModules.default`.
* LightDM's GTK greeter for [NixOS](https://docs.rtin.foo/bluecurve.nix/nixos/) via `bluecurve.nixosModules.default`.

The modules are independent; use either or both. Installation instructions and options are in the guides above.
