# Bluecurve for NixOS & Home Manager

Packages and modules for theming with [Bluecurve](https://github.com/neeeeow/Bluecurve),
[Bluecurve-Qt](https://github.com/neeeeow/Bluecurve-Qt) and [Bluecurve-KDE](https://github.com/neeeeow/Bluecurve-KDE).

## Features

- GTK, Qt and desktop environments (MATE, KDE Plasma, Xfce) for
  [Home Manager](home-manager/index.md).
- LightDM's GTK greeter for [NixOS](nixos/index.md).

The two modules are independent; use either or both.
