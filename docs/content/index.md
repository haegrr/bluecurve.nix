# Bluecurve for NixOS & Home Manager

Packages and modules for theming with [Bluecurve](https://github.com/neeeeow/Bluecurve),
[Bluecurve-Qt](https://github.com/neeeeow/Bluecurve-Qt) and [Bluecurve-KDE](https://github.com/neeeeow/Bluecurve-KDE).

## Usage

- [Getting started](getting-started.md): add the flake and configure standalone
  Home Manager.
- [Configuration](configuration.md): choose a variant, enable a desktop
  integration, and understand feature defaults.
- [Options](options.md): the generated reference for every public module option.
